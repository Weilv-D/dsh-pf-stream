# dsh-pf-stream 使用指南

插件页显示名为「视频理解」。本指南面向使用者与智能体：怎么用、参数是什么、返回什么、花钱在哪。
安装与首次设置见 [README](../README.md)；按现象排查见 [排障](排障.md)。

## 工具与 action 路由

一个主工具 `dsh-pf-stream`，按 `intent.action` 路由：

| action | 引擎 | 用途 |
| --- | --- | --- |
| `pf_stream`（缺省） | 动态流式采样 | 运动中抽 336² 过程单元（P）；停稳与清晰度波峰定格 672² 焦点单元（F）。施密特四状态机 + 双层自适应调节 |
| `timestamps` | 确定性检视 | 指定时间戳单帧或组合高清检视，支持 `roi_hint` 局部放大 |
| `uniform` | 确定性检视 | 固定步长或目标帧数均匀切片 |
| `probe` | 确定性检视 | 仅返回元数据（显示宽高、旋转、末帧 PTS、流摘要），零视觉 token |

选择建议：先 `probe` 看时长与分辨率；内容以运动为主用 `pf_stream`；已知时间点用 `timestamps`；只要概览用 `uniform`。

## intent 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `action` | `pf_stream` \| `timestamps` \| `uniform` \| `probe` | 缺省 `pf_stream` |
| `mode` | `dense` \| `standard` \| `sparse` | P 单元密度档位，缺省 `standard` |
| `focus` | `motion` \| `detail` \| `balanced` | 采样倾向，缺省 `balanced` |
| `roi_hint` | `{x, y, w, h}` | 归一化 ROI（[0,1]），作用于感知加权与视窗裁剪 |
| `full_frame` | boolean | 强制全画幅采样，禁用 1:1 质心裁剪 |
| `pts_window` | `[start_ms, end_ms]` | 处理时间窗（PTS 毫秒），越界钳制到流末帧 |
| `timestamps_ms` | number[] | `timestamps` 模式的目标时间戳（毫秒），越界钳制；数量上限 `maxFramesPerCall`（默认 128），超出报错请分段 |
| `interval_ms` | number | `uniform` 模式抽帧间隔（毫秒），必须为正数 |
| `frame_count` | number | `uniform` 模式目标帧数，受 `maxFramesPerCall` 钳制 |
| `max_packets` | number | 本次调用画布包数上限，受 `maxPacketsPerCall` 钳制；确定性检视（`timestamps`/`uniform`）缺省也按其钳制，触顶附截断提示行 |
| `max_tokens_budget` | number | 本次调用视觉 token 预算（≥274），受 `maxTokensBudgetPerCall` 钳制；预算装不下下一包时提前停止并附提示行 |
| `audio.mode` | `auto` \| `off` | 本次调用音频通道开关，缺省 `auto` |
| `audio.language` | string | 转写语言提示（如 `zh`），缺省自动检测 |
| `audio.extract_subtitles` | boolean | 本次 probe 是否提取字幕（最多 500 段，超出附 `truncatedSegments` 计数），缺省随配置 |
| `audio.assist_focus` | boolean | 本次调用是否启用台词辅助定格，缺省随配置 |
| `reset` | boolean | 先重置会话意图为默认基准，再合并本次传入字段 |

`uniform` 模式要求 `interval_ms` 或 `frame_count` 至少一个，缺失时返回 `PFSTREAM_UNIFORM_PARAMS_MISSING`。

## 顶层便捷字段

参数顶层接受 11 个视频检视领域常见字段，入口适配器将其归一化为标准 `intent` 结构：

`start_time`、`end_time`、`time_range`、`timestamps`、`fps`、`interval`、`num_frames`、`crop`、`bbox`、`roi`、`probe_only`。

时间类字段按秒或毫秒自动判别；`crop`、`bbox`、`roi` 三者等价，接受归一化或像素坐标（像素按显示宽高换算）。

## 调用示例

流式感知（分析画面内容与事件演变）：

```json
{
  "video_path": "D:/videos/demo.mp4",
  "intent": { "action": "pf_stream", "focus": "detail", "mode": "dense" }
}
```

定点复核（流式结果里发现 12.9s 处有文字，放大确认）：

```json
{
  "video_path": "D:/videos/demo.mp4",
  "intent": {
    "action": "timestamps",
    "timestamps_ms": [12900],
    "roi_hint": { "x": 0.2, "y": 0.3, "w": 0.4, "h": 0.4 }
  }
}
```

均匀切片（每 2 秒一帧概览）：

```json
{
  "video_path": "D:/videos/demo.mp4",
  "intent": { "action": "uniform", "interval_ms": 2000, "focus": "motion" }
}
```

## 听觉：台词是怎么来的

按三级顺位获取，前一级成功就不跑后一级：

1. **字幕**：同目录同名外挂字幕（`demo.mp4` → `demo.zh.srt` / `demo.srt`，多语言段 `demo.zh.en.srt` 也识别，中文优先，其次英文），或容器内的**软字幕**轨。文件编码支持 UTF-8，GBK 与 Big5 自动回退识别。
2. **语音转写**：没有字幕时，先做声学 VAD（静音直接短路，不产生费用），再按引擎设置转写。
3. **无语音**：既没字幕也不是语音，返回 `no_audio`，不报错。

转写引擎由配置里的 `audio.asr.engine` 决定，缺省 `auto`：

| `engine` | 行为 |
| --- | --- |
| `auto`（缺省） | 云端密钥、端点、模型都齐时用云端（更快，按量计费）；否则若官方语音输入插件模型就绪，复用它；再否则用已安装的本地引擎；都没有则不转写 |
| `local` | 优先复用官方语音输入插件模型；未就绪时用本地引擎 |
| `cloud` | 只用云端 |
| `host` | 只用官方语音输入插件模型；未就绪时明确报错，不回退 |
| `off` | 关闭转写（字幕仍然提取） |
| `legacy` | 兼容 0.2.x：按 `audio.asr.provider` 的旧语义走 |

当前实际使用哪个引擎，插件页标题旁会显示（如「转写可用 · 云端」「转写可用 · 官方语音」）。本地、云端与官方语音输入都在插件详情页设置，不需要改配置文件。转写文本是原文，不做翻译。台词按时间挂到对应画布包，提示行形如：

```text
Audio @Packet #42: [12.1s-12.9s] "这件事我们准备了三年" | [13.0s-13.4s] "今天终于可以说了"
```

### 复用官方语音输入插件

DSH 官方实验插件 `@deepseek-ai/dsh-experimental-voice-input-bundle` 自带 SenseVoice 本地模型。安装并在其插件详情页准备模型后，`dsh-pf-stream` 可以直接复用该模型，不再下载 whisper 模型。

启用条件：

1. 官方语音输入插件已启用。
2. 其本地 provider 处于 `ready` 或 `standby`（面板状态卡会显示「官方语音输入 · 模型已就绪」）。
3. `audio.asr.engine` 为 `auto` / `local` / `host`，且语言在该 provider 支持范围内。带地区标签的语言会归一化到 provider 列表中的精确值（如 `zh-CN` → `zh`）；空白语言按自动识别处理。

行为边界：

- `auto` 仍先看云端；云端配置完整时不会改用官方模型。
- 旧版 `audio.asr.provider` 非 `none` 且 `engine=auto` 时仍按 legacy 配置执行，不会自动切换到官方模型。要复用官方模型，请把 `engine` 设为 `host`，或清空旧 `provider`。
- 模型未准备时只提示，不自动下载。请先在官方插件里完成准备。
- 官方 provider 只返回块级文本，没有段内时间戳；本插件按不超过 15 秒的语音岛切块，台词时间精度为块级。
- 首次调用可能需要唤醒官方 worker，耗时会高于后续调用。
- 音频只在本机处理，不上传云端。


`audio.status` 常见值：`ok`、`partial`（部分块失败）、`no_audio`、`silent`（有声但没检出有效语音）、`no_subtitle_asr_unconfigured`（没字幕也没引擎）、`disabled`、`timeout_skipped`、`error`。`timeout_skipped` 表示这一轮先回画面，转写在后台继续并写入缓存。

## 会话级行为

- **意图持久化**：`mode`、`focus`、`roi_hint`、`full_frame` 跨调用字段级合并；`reset: true` 先清空再合并本次新字段。
- **游标续窗**：同视频再次流式调用，从上次消费位置继续；到达流末帧后 `stopReason` 为 `end_of_stream`。
- **状态落盘（storageDomain）**：会话快照（游标、意图、两级历史、冷区）经宿主 `storageDomain` 持久化，进程重启后同会话从最近一次成功调用续接，不再从头重放；显式传 `pts_window` 时仍按显式窗口执行。pf_stream 每次成功调用写一次（单次写盘超过 2 秒先返回，写入继续）；保留最近 8 个会话。宿主未提供 `storageDomain`（无存储后端）时自动降级为内存态，并在首次需要落盘时于宿主日志给一条告警；配置 `persistSessionState: false` 关闭时不尝试打开领域，也不打日志。
- **墙钟保护**：解码推进超过单次墙钟上限（`maxWallClockMsPerCall`，默认 720s）即停止，`stopReason` 为 `wall_clock` 并附提示行；已消费窗口按游标续接不会重放。整段低出包内容（如台词片）给超长 `pts_window` 时靠这道门兜底——建议单窗跨度 ≤240s。
- **确定性检视包数上限**：`timestamps`/`uniform` 缺省也按包数上限钳制（与宿主 20 图上限对齐，保证每包都有画布）；触顶或触预算时停止并附提示行，时间轴尾部未采样会如实告知，缩小 `pts_window` 或分批即可续看。
- **会话标识**：取宿主调用的会话 ID；宿主未提供时归并到 `default` 会话。
- **并发串行化**：同会话的调用按到达顺序串行执行。
- **两级历史引用**：热区（最近 2 包）整条带复用；冷区至多 4 个 F 锚点独立载体（672²，274 token）复用。
- **Epoch Compaction**：每 6 包批量热转冷，多轮对话中历史位置图像字节保持不变，Prefix KV-Cache 前缀稳定。
- **超时与取消**：单次调用最长阻塞 15 分钟；取消为协作式，解码循环在下一个帧边界停止。

## 返回内容

每次调用返回一个文本块与若干图像内容块：

- **文本块**：结构化元数据 JSON。含每个画布包的 `packet_id`、形态、触发路径、双载体 SHA-256、逐单元 PTS 与 bbox、遥测（解码耗时、ffmpeg 调用参数、控制参数快照、预检结果）；带语音时另有 `audio` 与每包的 `audio` 挂载。
- **图像内容块**：每包一张画布 PNG，提交宿主附件服务后进入模型上下文。单次至多回传 `maxImagesPerCall` 张，超出时保留最新包，旧包仅回元数据。
- **时序提示行**：模型可读的 P/F 单元时间轴，如 `[Packet #42 | Anchor: #105 | #101(P, 12.1s, Left-Top) → …]`。
- **心跳**：长静止期间每 5 秒（PTS 域）一条心跳记录，触发状态体检。

## 画布与计费

| 形态 | 布局 | 尺寸 | Token |
| --- | --- | --- | --- |
| `FORM_1_STANDARD_STRIP` | 4P + 1F | 1344×672 | 530 |
| `FORM_2_COMPACT_4P` | 4P | 672×672 | 274 |
| `FORM_3_COMPACT_1F` | 1F | 672×672 | 274 |
| `FORM_4_PARTIAL_STRIP` | 1-3P + 1F | 1344×672 | 530 |

单元间双色隔离线阻断相邻边缘特征串扰；`renderVisualId` 开启时单元左上角渲染超像素反色角标。

## 设置页

**左侧栏「插件」→ 点「视频理解」→ 详情页描述下方的面板**：

1. **状态卡**：ffmpeg、本地引擎、云端密钥三条链路各自是否就绪；装了官方语音输入插件时多一张「官方语音输入」卡。
2. **设置路线**：下载本地模型（一键，含进度与取消）；填云端密钥（预设 + 自定义兼容端点）；或直接复用已准备好的官方语音输入模型，不再下载本地模型。
3. **高级**：引擎策略、语言、模型大小、线程数、转写缓存占用与清理。

「清理转写缓存」只删按文件与引擎生成的台词 JSON，可以重新转写；画布图片在宿主附件库里，属于会话历史，不在这个按钮的范围内。模型与引擎文件也保留，需要重下时点「重新下载本地模型」。

「测试转写」会跑一次真实短音频，验证「引擎 + 模型 + 参数」整条链路，而不只是检查文件存不存在。`engine=host`，或 `auto`/`local` 实际选中官方语音时，按钮变为「检查官方语音就绪」，只检查官方 provider 是否就绪；真实转写会在处理视频时执行。

## 配置

面板能改的都在上面；下面是完整配置，也可以直接写进 `cordis.patch.yml`。

### 常用

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `renderVisualId` | `true` | 单元左上角超像素反色角标 |
| `maxPacketsPerCall` | `20` | 单次调用画布包数上限（与宿主 20 图上限对齐，保证每包都有画布） |
| `maxFramesPerCall` | `128` | 确定性抽帧单次目标帧数上限 |
| `maxImagesPerCall` | `20` | 单次调用回传图像上限（宿主单条消息图像上限 20） |
| `maxTokensBudgetPerCall` | `65536` | 单次调用视觉 token 预算上限 |
| `maxWallClockMsPerCall` | `720000` | 单次调用解码推进墙钟上限（毫秒）；超长窗口到点即停（`wall_clock`），先于客户端 900s 超时收敛 |
| `maxRequestBytes` | `56 MiB` | 请求字节软水位（含 Base64 膨胀与协议结构预留） |
| `maxColdRefs` | `4` | 冷区引用数量上限 |
| `telemetryEnabled` | `true` | 遥测字段开关 |
| `persistSessionState` | `true` | 会话状态经宿主 storageDomain 落盘（重启后续接；无 storageDomain 时降级内存态） |

### 路径与解码

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `ffmpegPath` | 自动探测 | ffmpeg 可执行文件路径 |
| `ffprobePath` | 自动探测 | ffprobe 可执行文件路径 |
| `tempDir` | 系统临时目录 | 临时文件目录 |
| `contentHashFallback` | `false` | 宿主重编码画布时改用规范化像素内容哈希做载体比对 |
| `defaultStreamWindowMs` | `10000` | `pts_window` 缺省时的流式窗口长度（毫秒） |
| `streamWorkMaxEdge` | `2048` | 流式解码工作分辨率长边上限；确定性检视恒全分辨率 |
| `epochCompactionWindow` | `6` | 热转冷批量收敛窗口（包数） |

### 音频

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `audio.mode` | `auto` | 音频通道模式（`auto` 启用；`off` 关闭） |
| `audio.extractSubtitles` | `true` | probe 时提取内嵌/外挂字幕 |
| `audio.assistFocus` | `true` | 台词密集停顿时软增强高清定格 |
| `audio.sliceCodec` | `mp3` | 音频切片编码（`mp3` 或 `opus`） |
| `audio.cacheDir` | `~/.dsh/cache/dsh-pf-stream` | 转写缓存、模型与引擎的根目录（按文件指纹复用） |
| `audio.graceMs` | `8000` | 转写软截止宽限（毫秒）；超时先回视觉结果 |
| `audio.asr.engine` | `auto` | `auto` / `local` / `cloud` / `host` / `off` / `legacy` |
| `audio.asr.preset` | `openai` | 云端预设：`openai` / `groq` / `custom` |
| `audio.asr.baseUrl` | 随预设 | 云端接口地址（OpenAI 兼容协议） |
| `audio.asr.model` | 随预设 | 云端模型名；`local_cli` 时是可执行文件路径 |
| `audio.asr.apiKey` | 空 | 尽量不用：面板会写进宿主凭据存储；环境变量 `DSH_ASR_API_KEY` 优先 |
| `audio.asr.language` | 自动识别 | 转写语言；本地引擎不填时由引擎自动判断 |
| `audio.asr.local.binPath` | 托管目录 | 自备本地引擎的可执行文件路径 |
| `audio.asr.local.modelPath` | 托管目录 | 自备模型文件路径 |
| `audio.asr.local.modelId` | `small-q5_1` | 托管模型：`base-q5_1` / `small-q5_1` / `medium-q5_0` |
| `audio.asr.local.threads` | `0` | CPU 线程数，`0` 由引擎决定（上限 16） |
| `audio.asr.local.timeoutMs` | `300000` | 本地单块转写超时 |
| `audio.asr.args` | 随引擎 | 高级：`local_cli` 参数模板，一般不用改 |
| `audio.asr.timeoutMs` | `8000` | 云端单块转写超时 |
| `audio.asr.maxConcurrency` | `2` | 长音频分块转写并发数 |

`local_cli` 参数模板的令牌：`{audio}` 音频路径、`{out}` 输出文件、`{outbase}` 输出基名（whisper.cpp `-of` 用）、`{dir}` 临时目录；无 `{audio}` 时音频路径追加在末尾。含 `{out}` / `{outbase}` / `{dir}` 时优先读产物文件，stdout 仅作兜底。

### 计量

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `meteringProfile.maxTokensPerImage` | `1024` | 单图视觉 token 上限 |
| `meteringProfile.maxImagesPerRequest` | `600` | 单次请求图像张数上限 |
| `meteringProfile.imageCountTiersEnabled` | `false` | ≥15 图单边 4096px 规则门控 |

`meteringProfile.superpixelPx` 固定为 `42`，`rounding` 固定为 `ceil`，`legacyModes` 为 legacy 计量口径枚举位，均无需配置。

可执行文件定位顺序（`ffmpeg` 与 `ffprobe` 同序）：`ffmpegPath`/`ffprobePath` → 环境变量 `DSH_FFMPEG_PATH`/`FFMPEG_PATH`（精确路径或其所在目录）→ `DSH_FFMPEG_DIR`（内含两个可执行文件的目录）→ `~/.dsh/tools/ffmpeg/bin` 与 `~/.dsh/bin` → 系统 `PATH`。

### 自备本地引擎

已经装了 `whisper-cli`、`whisper-ctranslate2`、`faster-whisper` 或 OpenAI `whisper` 的，插件会先探测 PATH 与托管目录；也可以显式指定：

```yaml
audio:
  asr:
    engine: local
    local:
      binPath: C:/tools/whisper/bin/whisper-cli.exe
      modelPath: C:/tools/whisper/models/ggml-small-q5_1.bin
```

## 错误码

| 前缀 | 含义 |
| --- | --- |
| `PFSTREAM_ARGS_*` | 参数校验失败（`VIDEO_PATH` / `ACTION` / `MODE` / `FOCUS` / `WINDOW` / `TIMESTAMPS` / `INTERVAL` / `FRAME_COUNT` / `PTS` / `ROI`） |
| `PFSTREAM_PROBE_NOT_FOUND` | 视频路径不存在或不是常规文件 |
| `PFSTREAM_PROBE_NO_VIDEO` | 容器内不存在视频流 |
| `PFSTREAM_PROBE_FAILED` | 媒体探测失败（含容器损坏） |
| `PFSTREAM_SPAWN_FAILED` | ffmpeg / ffprobe 进程无法启动 |
| `PFSTREAM_EXEC_NONZERO` | 子进程非零退出（附 stderr 尾部） |
| `PFSTREAM_EXEC_ABORT` | 调用方取消 |
| `PFSTREAM_EXEC_TIMEOUT` | 子进程执行超时 |
| `PFSTREAM_EXEC_OUTPUT_TRUNCATED` | 子进程 stdout 超过 64 MiB 上限被截断，结果不完整 |
| `PFSTREAM_DECODE_EMPTY` | 指定时间点无可解码帧（含末尾避让后的回退穷尽） |
| `PFSTREAM_DECODE_STALL` | 解码连续 30 秒无帧推进，已终止 |
| `PFSTREAM_UNIFORM_PARAMS_MISSING` | `uniform` 缺少 `interval_ms` 与 `frame_count` |
| `PFSTREAM_CANVAS_EDGE_OVER_LIMIT` | 画布单边超出像素上限 |
| `PFSTREAM_CANVAS_TOKEN_OVER_LIMIT` | 画布计费超出单图 token 上限 |
